Project Title: TheProcess

Student Name: Dumlan, Hallee Husie

Website Category: Appointment Booking / Service Management (small business, barbershop)

Project Description:
TheProcess is a haircut booking website for a barbershop. Customers can browse the available services, choose a barber, and reserve a date and time online. The system checks every form, blocks past dates, Sundays, and time slots that are already taken, and keeps each customer’s bookings in their own account. It is built with plain HTML, CSS, and JavaScript, and it works on desktop, tablet, and mobile.

Main Features:

Home page with live counts of services, barbers, and bookings, plus shop hours
Services page with search, category filter, and sorting by name or price
Barbers page with a profile card and photo for each barber
Booking form with validation and a live price summary
Double-booking prevention, with taken time slots disabled
My Bookings page where customers can view and cancel their appointments
Registration and login with form validation
Responsive layout for desktop, tablet, and mobile

Technologies Used:

HTML5: page structure
CSS3: styling, grid, flexbox, responsive design, CSS variables
JavaScript (vanilla): events, form validation, dynamic content, search and filtering
JSON and localStorage: data lists and saving accounts and bookings in the browser
Google Fonts (Bebas Neue): heading font
Visual Studio Code: code editor
